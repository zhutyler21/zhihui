# 粤语转写验收记录

日期：2026-10-16。对象：已安装 `~/Applications/知会.app`，0.6.0 / build 17。

## 功能与操作

现有版本的语音模型、后端和原生语言选择已包含粤语 `yue`。本轮单独验证该能力，补齐使用说明与可重复运行的验收脚本；没有更换模型、增加下载、重新安装应用或调整系统权限。

1. 新建或打开会议，点击“语言与实时翻译”。
2. “讲话语言”选择“粤语”，保存设置。
3. 不需要译文时，保持“录音时显示译文”关闭；粤语识别仍会生效。
4. 开始录音，或从会议更多菜单导入音频。讲话语言只影响之后提交的音频，不会自动重转写已有原文。
5. 完成转写后生成中文纪要，或使用“停止并整理”；粤语口语原文保留，纪要正文使用简体中文。

粤语是本次的语音输入选项。没有新增粤语配音、粤语译文目标或说话人分离。

## 实际验证

脚本：[verify-cantonese.py](../scripts/verify-cantonese.py)。调用已安装 App 内的独立 Python、后端和 FFmpeg；校验 App 身份、严格签名、服务身份及固定模型文件。模型按清单验证后克隆到项目 `work/`，不联网下载。系统隔离规则禁止外网和读取日常资料，额外探针验证外网连接确实被系统拒绝。

输入是本机已安装的 macOS `Sinji`（`zh_HK`）声音生成的 12.22 秒合成音频，不是真人录音：

> 今日我哋開會討論新項目。預算係三萬一千四百七十二蚊。由陳小姐負責，十一月九號之前交方案。下次開會再確認合約。

复现命令（在仓库根目录；使用项目内自建测试音频）：

```sh
mkdir -p work/cantonese-20261016/audio
say -v Sinji -r 165 -o work/cantonese-20261016/audio/yue.aiff '今日我哋開會討論新項目。預算係三萬一千四百七十二蚊。由陳小姐負責，十一月九號之前交方案。下次開會再確認合約。'
.venv/bin/python scripts/verify-cantonese.py --audio work/cantonese-20261016/audio/yue.aiff
```

该脚本只适用于上述含预算 31472 的合成夹具。`say` 声音需已安装；没有声音时不要以其他语言声音冒充粤语。

## 观察到的限制

- 本条转写首词“今日”漏掉“今”，实际以“日我哋……”开始；标点也有省略。不能将通过的结构与事实检查描述成逐字完全正确。
- 金额被正确保留为中文“三万一千四百七十二”，没有统一转换成阿拉伯数字。首次脚本过于狭窄地要求 `31472`，因此失败；`verification.log` 保留原结果。修正只接受相同金额的精确中文写法或数字写法后再验收，没有改写原文来制造通过。
- “蚊”不自动确定是人民币还是港币，纪要保留原文的单位；币种需由讲话内容或人工校对明确。
- 两种模式仅共享这一条合成声音，不能推定不同粤语口音、普通话夹杂、噪声、多人重叠讲话或长会议都达到相同准确率。重要的人名、金额与日期仍需校对。
- 打开隔离资料的原生安装包时，真实权限页显示麦克风已允许、系统声音未允许（1/2）。按用户要求没有继续配置，也没有绕过进入检查。本轮没有在主界面实录或再次操作语言菜单；入口依据当前 SwiftUI 源码，功能依据已安装后端的真实模型与持久化验证。
- SwiftUI Expert 与 ui-ux-pro-max 用于复核现有原生语言设置；本轮未更改界面或重新声称完成浅深色视觉验收。前一轮结果保留其原范围。
