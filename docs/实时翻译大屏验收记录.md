# 实时翻译大屏验收记录

版本：0.7.0 / build 18。日期：2026-10-16。范围：本机 Apple Silicon、macOS 14 最低目标；新增独立原生大屏和多个翻译目标。0.6.0 的四语及粤语历史记录保留原范围。

## 使用与实现

1. 在本场会议的“语言与实时翻译”中选择讲话语言；译文可勾选中文、英文、日文、韩文中的一种或多种，开启翻译后保存。输入支持自动、中文、英文、日文、韩文、粤语。
2. 点击会议上方“实时翻译大屏”。窗口绑定打开时的会议，按同一片段并排显示原文和各目标语言，逐栏更新。可以移到外接屏后全屏；Esc 退出。
3. 显示原文、跟随最新、暂停显示、24–64 号字幕、独立深浅色、补齐译文均在大屏操作。暂停只冻结显示，后台录音和翻译继续保存。
4. 每次只投屏本场最近 30 段，已删除片段不显示；本场移入回收站后清屏。投屏接口不包含笔记、摘要或附件正文。完整会议仍保留所有原文、译文与中文纪要，可导出 Markdown。
5. 一段音频只产生一份原文，再提交各目标语言任务。语音识别和文字任务独立；译文共用一个已加载的本地 Qwen 模型依次生成，每种语言独立保存状态、失败和重试。旧单目标设置迁移为单元素数组，仍接受旧接口字段。

关键文件：`Sources/ProjectionView.swift`、`ProjectionState.swift`、`TranslationViews.swift`、`AppModel.swift`、`Main.swift`；`backend/server.py`、`store.py`、`translation.py`、`engines.py`。新增接口为 `GET /api/meetings/{id}/projection`；翻译设置和提交支持 `target_languages`。录音与导入队列保存发起时的目标列表，重开和设置变化不改写已排队音频的语言。

沿用固定的 SenseVoice + Silero、Qwen3-4B MLX 4bit、BGE-small-zh 模型体系，没有增加权重或云端推理。原文与最终纪要仍以本场证据为基础，译文不作为事实来源重新摘要。

### 实际窗口验证

通过 CUA 操作最终源文件编译的原生窗口，观察实际界面与合成资料；没有用效果图替代运行结果。

- 在主窗口点击入口打开独立大屏，同一会议重复打开复用窗口；展示原文及四个译文栏，共五栏。
- 深色 32 号、浅色 24 / 28 号及原文隐藏均检查；本机窗口菜单的 Left 和 Top Left 排列检查到最小约 1000 × 650 内容区，操作均可见，长文可滚动。不是任意字号、任意长度都能一屏完整显示。
- 发现旧懒布局初次打开可能停在上一段中间，且大字号跟到底部会裁掉新段句首。最终改为限定 30 段的普通布局，布局完成后跟随最新段开头；再次打开、改列数、字号和窗口尺寸已复核。
- 暂停后在隔离后端真正提交英文音频，并完成四种译文；暂停屏未出现 00:24，恢复后出现该段及译文。`ui-live-update.json` 读回 3 段及 12 份译文。该检查在最终布局调整前执行，暂停控制器及后端之后未改；最终布局另行验证。
- 对隔离样本的日文译文注入一个受控失败，实际界面显示重试提示，点击“补齐译文”后，`ui-retry-readback.json` 核对原文和四种译文完成；其他语言保留。该故障是主动注入，不冒充自然模型失败。
- 通过系统菜单“Move to LG ULTRAWIDE”移到本机连接的外接显示器，点击本窗口“全屏”后标题栏消失，Esc 返回；之后菜单显示“Move to Built-in Retina Display”，与已移动结果一致。未测试其他投影仪、4K 显示模式或会议现场。
- 停止自己拥有的隔离服务后，大屏保留上一屏并显示“连接中断，保留上一屏，正在重试”。验收应用随后正常退出。
- 字幕与按钮具有可访问性标签。按 Tab 已执行，但当前系统设置下未建立所有按钮逐一出现焦点环的证据；没有为验证修改系统键盘设置。

技能实际使用：REA 用于上述发布脚本分析；SwiftUI Expert 用于按会议值绑定窗口、可观察状态与窗口全屏实现；ui-ux-pro-max 用于层次、对比和间距，采用本项目 SwiftUI / Design.swift，不采用网页框架。Context7 查询 SwiftUI 的 WindowGroup / openWindow 当前用法，结果保留在 `swiftui-docs.txt`。

## 质量发现与限制

首轮真实模型虽然通过结构读回，但内容复核发现粤语“蚊”被擅自解释为港币，以及韩文增加原文没有的“下周”。历史 `integration-8875404f6d874384a18b3ce786db92b9/receipt.json` 和 `real-models.log` 保留原始结果，不作为质量合格结论。新增明确歧义币种保持原词、常见相对时间增补/遗漏检查及有限重试，回归和最终样本通过对应约束。

最终输出仍存在识别人名“陈洁 → 陈杰”、粤语开头“今日”漏字、韩文“陈小姐”误译等问题。数字、时间及字种检查只能识别部分问题，不能证明语义或专业同传质量。重要会议应预先试音，关键人名、金额、决定和期限对照原文校对。

实时链路仍以约 2–6 秒短块发布原文，再排队翻译，混音另有约 2 秒缓冲；多目标不是同一瞬间完成。最终两条约 12 秒导入样本全链路耗时分别为 8.341、11.490 秒；此时另有独立包验证使用模型，且包含模型加载/排队，不是现场字幕延迟指标。长会议、多路并发、大量会后补译时的积压没有耐久性证据。

按用户要求，不进入系统设置、不重置或重新添加 TCC，不测试真实麦克风和系统音频。生产权限及模型进入门禁保留真实判断；QA 的直接入口仅用于视图验证。当前是本机独立大屏，未实现局域网网页链接、跨设备同步或云端会议分发。

本次没有制作 0.7.0 DMG 或发布远端 Release；公开 0.5.0 的发行记录仍属于旧版。当前 App 是 ad-hoc 签名，未经过 Apple 公证；本机验证不代表所有设备均已验证。
