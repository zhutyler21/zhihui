# 会议交互优化

版本：0.7.2 / build 20，2026-10-16。基于当前 0.7.1 的资料页和实时会场，优化常用操作的位置及转写、笔记的协作方式。

## 最终交互

| 位置 | 行为 |
| --- | --- |
| 侧栏与会议列表 | 增加边缘留白，保持原生选择、搜索和键盘操作 |
| 全局右上角 | 各页面始终显示带文字的“新建会议”；知识库另保留“添加资料” |
| 新建会议、会议资料与实时会场 | 直接提供“开始录音”“导入音频”；声音来源就在会议标题下方 |
| 正在录音 | 内容区顶部持续显示录音状态、计时、“停止录音”和“停止并整理”；切到其他页面仍可控制原录音会议 |
| 转写与笔记 | 默认同时显示，宽窗口左右分栏，窄窗口上下分栏；可拖动分隔线，也可关闭并排模式专注一个内容标签。高度不足时可滚动到下方笔记 |
| 笔记格式提示 | 按需打开提示，给编辑区保留空间；完成后保存并显示 Markdown 预览 |
| 实时会场 | 继续集中翻译、语言设置和投屏操作；进入与返回保留资料标签和笔记编辑模式 |

“停止录音”保存录音并继续转写；“停止并整理”保存录音、等待本场剩余转写，再生成纪要。录音中的声音来源锁定；另一场会议正在录音、音频导入未完成、正在整理等状态会阻止不合适的重复操作。

新建会议先保存原会议笔记，保存失败时保留原选择和草稿，不创建空会议。创建期间禁用重复点击。多个停止入口共用同一停止过程，等待录音尾部发布和队列持久化后再返回。异步按钮执行时重新核对会议 ID，不把迟到操作用于另一场会议。

笔记会话保存在分栏容器的上层，并按 meeting ID 重建；缩放、并排开关与内容标签变化保留草稿和编辑模式。进入实时会场后，隐藏资料视图不可交互，隐藏笔记清除键盘焦点；返回后恢复编辑焦点。跨横竖布局时不保证原生编辑器的光标位置或撤销栈保持。

## 设计依据与技能

本次使用 Apple 官方 [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Split views](https://developer.apple.com/design/human-interface-guidelines/split-views) 和 [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)。这些指南支持原生窗口、明确的常用操作、可调整的内容分栏与可缩放布局；具体操作位置是本项目结合用户反馈的设计选择。

- [SwiftUI Expert](https://github.com/AvdLee/SwiftUI-Agent-Skill)：用于状态所有权、视图身份、原生工具栏、分栏、焦点与 macOS 14 兼容。现有用户级技能已读取并用于实现，无需重复安装。
- ui-ux-pro-max：检索 SwiftUI 栈和交互指南，用于操作主次、状态反馈、留白、深浅色与可访问性。其网页式配色、字体及营销页面建议不适用于本项目，实际沿用 Design.swift、系统字体和 SF Symbols。
- Context7：先解析 `/websites/developer_apple_swiftui`，再查询原生工具栏、HSplitView 与可访问性。Apple 官方 Markdown 指南保存于本轮 work 目录。

主要改动：`Sources/MeetingWorkspace.swift`、`NativeNavigation.swift`、`Views.swift`、`MarkdownNotesView.swift`、`MeetingLiveView.swift`。AppModel 增加创建前保存及共享停止门禁；Main 菜单同步禁用规则。构建和安装版本同步更新，中英文 README 同步操作路径。
