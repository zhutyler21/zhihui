# 知会原生界面升级

本轮将主界面调整为 macOS 的侧边栏、可调整宽度的会议列表、统一工具栏和原生资料表格。新一轮精修使用海盐蓝、暖白和雾蓝底，小面积青绿表达本机处理与成功状态。字体整体放大，标题使用圆润系统字形，正文保持 SF / PingFang 的清晰阅读感。品牌标识使用纯色填充，移除紫色渐变。系统图标及系统按钮保留键盘焦点、禁用、选中和按下反馈。

## 布局与交互

- 工作空间采用 `NavigationSplitView` 与 `.sidebar` 原生 `List`，入口仍为会议、知识库、提问、回收站。会议列表使用原生选中行，按日期、转写数量、附件数量显示必要信息。
- 会议区使用原生 `HSplitView` 拖动分栏，列表宽度 238–390（理想 282），详情最小宽度 480 并占据剩余空间。避免嵌套导航分栏造成重复侧边栏布局偏移。品牌区域沿左对齐，侧边栏内容宽度由外层分栏约束。外层工具栏使用 macOS 系统侧边栏开关，会议、知识库和提问均由同一外层分栏提供入口；没有自定义重复开关。主窗口最小宽度 1080、最小高度 700，默认尺寸 1280 × 850。
- 标题栏与工具栏使用原生 unified 样式。新建会议、添加资料、本地模型状态置于工具栏；会议自身保留名称编辑、声音来源、录音、提问、导出与回收站入口。
- 知识库采用原生 `Table`，包含资料名称、关联会议、读取状态、添加时间，支持名称筛选、列排序、行选择、双击预览、右键操作，以及可通过键盘到达的预览按钮。
- 会议内容使用原生分段控件。Markdown 笔记改为源文本编辑，完成保存后切换为排版阅读；摘要和回答复用同一原生渲染器，具体支持范围见 [Markdown笔记.md](Markdown笔记.md)。
- 新增小型原生设置窗口，提供跟随系统、浅色、深色三种外观，只影响知会。窗口、侧边栏、内容区、转写校对、资料/引用预览均使用适应外观的颜色。
- 放大字号后，侧边栏最小宽度 184、理想宽度 208；会议行保留双行长名称，窄列表下日期和转写/附件数量会分行。知识库资料行最小高度 38，完整文件名可通过悬停与预览查看。问答范围提示不足一行时移到下方，避免挤压指定会议选择器。编辑器可用高度随窗口调整，不以固定大高度挡住完成按钮。

## 字号与排版

字号统一集中在 `Design.Typography`（`Type` 为 Swift 元类型保留名称）。应用内容的基础字体设为正文 16，自己绘制的文字均使用同一层次；系统菜单、标题栏和系统对话框仍遵循 macOS 字体。

| 层次 | 字号 | 用途 |
| --- | --- | --- |
| largeTitle | 32 | 知识库、提问、回收站页面标题 |
| title | 28 | Markdown 一级标题 |
| title2 | 24 | 会议名称、品牌名、二级标题、弹窗标题 |
| title3 | 20 | 空状态标题、三级标题、模型弹窗标题 |
| headline | 17 | 内容区的小标题 |
| body | 16 | 转写、笔记、Markdown、资料与引用正文 |
| callout | 15 | 按钮、选择器、输入框、文件关联会议 |
| caption | 13 | 日期、引用编号、任务状态、辅助说明 |

标题使用 `.system(..., design: .rounded)` 与适度半粗字重，正文沿用原生字体，没有下载外部字体。转写与 Markdown 正文行距 7，Markdown 标题和段落间距随层次变化；代码、原文编辑使用等宽字体，计时和表格时间使用等宽数字。笔记 Markdown 阅读区最大宽度 840，窄表格继续折为带表头的分组行，避免中文挤成单字列。叶子文字的选中、复制与无障碍结构保持既有修复。

## 颜色与可读性

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 蓝色文字与链接 | `#365CBA` | `#A9C4FF` |
| 蓝色填充按钮 | `#365CBA` | `#496BC6` |
| 青绿状态 | `#247C78` | `#7CD4C9` |
| 画布 | `#F7F8FA` | `#202831` |
| 淡色内容背景 | `#F0F4FA` | `#293446` |
| 次要文字 | `#5B687A` | `#BDC8D7` |

正文、内容背景和分隔线使用 macOS `labelColor`、`textBackgroundColor`、`separatorColor` 语义颜色。默认 tint 使用文字蓝色，供链接、普通按钮和 Popup 选择器使用；填充按钮、会议分段控件和外观分段控件单独覆盖填充蓝色，以保证深色下白色按钮文字可读。录音使用系统红色，并同时显示文字和计时，不仅依赖颜色表达状态。问答自动滚动尊重“减少动态效果”。图标按钮提供中文无障碍名称，正文和引用仍可选中、复制。

## 数据与生命周期保护

后端、录音器和 `AppModel` 保持现有实现。会议切换仍由模型先保存笔记，并保持原有切换禁用、最新响应保护、错误反馈和录音保留机制。侧边栏等待保存后，只有导航票据、原工作空间和原会议仍一致时才提交；后来的快捷键或程序化导航会使旧提交失效。

Markdown 编辑通过既有笔记接口保存，完成按钮在保存失败时保留编辑状态。退出、导入、范围变化取消问答、回收站恢复、原文引用等路径仍接入既有方法。

主场景使用命名 `WindowGroup("知会", id: "main")`，继续保持关窗不退出。`App` 级 `StateObject` 保留同一个会议模型、草稿和本地服务；主窗口内容提供环境中的 `openWindow(id: "main")` 回调。Dock/Finder 重开只要主窗口不可见（包括弱引用已释放），就由 SwiftUI 恢复场景，不直接显示已关闭的旧 `NSWindow`。退出保存失败时也用这一回调恢复已关闭的主窗口。[SwiftUI 窗口文档](https://developer.apple.com/documentation/swiftui/environmentvalues/openwindow)

仅用于主场景的 `NSViewRepresentable` 注册当前窗口的稳定身份，避免根据窗口标题识别；窗口只保存弱引用。设置窗口仍可见时，判断依据也是主窗口自身的可见状态。该桥接视图不响应点击，也不进入无障碍树。已通过回调处理的重开事件返回 `false`，避免 AppKit 再创建无标题窗口。[AppKit 重开文档](https://developer.apple.com/documentation/appkit/nsapplicationdelegate/applicationshouldhandlereopen(_:hasvisiblewindows:))

## 采用的资料与验证范围

本轮遵循 [SwiftUI Expert Skill](https://github.com/AvdLee/SwiftUI-Agent-Skill) 的 macOS views、window styling、navigation、toolbar、layout、accessibility 和 latest APIs 参考；同时采用本机 UI/UX Pro Max 的对比度、键盘可达、减少动态效果及轻量反馈原则，及 Redesign Skill 的字体层次、克制配色和现代留白。本轮保留原生 Mac 结构，界面使用系统字体与系统控件。两份本机技能文件属于开发环境，不随公开仓库提供。

Context7 的 SwiftUI 导航、Markdown 和字体文档由主线程取得，保存在 `work/context7-swiftui-navigation-v2.txt`、`work/context7-swiftui-markdown-v2.txt` 与 `work/context7-swiftui-typography-v3.md`。所用 API 以本机 SDK 验证可用于 macOS 14，没有强制引入更高版本的 Liquid Glass 或新 SDK 专属效果。

静态验收使用完整 `Sources/*.swift` 的 macOS 14 arm64 typecheck，以及 `git diff --check`。这能证明源代码可通过类型检查，不证明已安装应用的外观、窗口缩放、键盘、浅深色切换和关闭重开；这些需要主线程在最终构建上进行真实界面验收。Markdown 解析和保存交互的回归证据另由 Markdown 工作线程保留。
