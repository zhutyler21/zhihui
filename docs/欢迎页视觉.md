# 知会欢迎页视觉与接入

欢迎页是一段首次使用的轻量引导。左栏使用知会自己的品牌、圆润大标题、三条实用说明和始终可用的原生“开始设置”按钮；右栏展示声音、笔记、资料、问答四张原创浮动纸片，围绕一枚折射玻璃球。配色沿用海盐蓝、雾白和少量青绿，不使用参考项目的字标、图片、视频、贴纸或源代码。

## 接口与职责

```swift
WelcomeView(onContinue: { /* owner moves to the next setup step */ })
```

唯一业务动作是 `onContinue` 回调。页面不会请求任何权限、录音、读取用户会议、启动服务或连接网络。原生按钮提供默认 Return 快捷键，Tab 能到达开始按钮及辅助动效按钮。拖动装饰不是继续的前置条件；“暂停动效”和“重播”只影响这一页的局部视觉状态。

界面最小尺寸 980 × 640，使用 Mac 横向双栏，内容不足高度时可原生滚动。正文、辅助文字和按钮沿用应用字体层次，展示标题为系统圆润 42 pt。装饰与真实用户数据分开，整块 artwork 从无障碍树隐藏；主文案、功能说明和原生控件仍可访问。

## 原创交互

玻璃初始是右栏底部的一座大穹顶，自动收拢到中央的球体。用户从球内拖动，上下位移改变球心和半径，横向位移受到柔和约束；释放后的目标由预测位移决定，用解析阻尼弹簧收敛。再次抓取会读取当前呈现位置，而不是先前的动画目标。球只负责探索视觉，不能替代开始按钮。

只有右栏 artwork 使用 `TimelineView`，以 1/60 秒最小更新间隔为目标；页面文字、按钮和其他应用界面不进入逐帧计算。卡片数量固定为四张，没有粒子发射和外部资源。窗口 inactive、手动暂停、减少动态效果或减少透明度时不逐帧运行；逻辑时钟冻结，恢复后继续，不把后台经过时间一次跳过去。暂停期间拖动被取消并保留当前呈现。

减少动态效果、减少透明度或缺少 shader 资源时，采用静态不透明球体与原生图标，不执行折射 shader。辅助说明标明“静态展示”，开始设置始终可用。取消辅助设置后使用已收拢的稳定球体，不重播大范围空间运动。

## SwiftUI / Metal 契约

资源名称为主 bundle 的 `default.metallib`，原始文件为 `Resources/WelcomeGlass.metal`。唯一函数名为 `zhihuiWelcomeGlass`，签名如下：

```metal
[[ stitchable ]] half4 zhihuiWelcomeGlass(
  float2 position, SwiftUI::Layer layer,
  float2 viewport, float2 center, float radius,
  float time, float force, float night);
```

SwiftUI 的 argument 顺序与上述一致，viewport / center 单位为 point，time 为局部逻辑秒数。`night` 为 0 或 1，`force` 是交互高光强度。`layerEffect` 只包裹原创 `Canvas` 内容；AppKit、文字编辑器、真实按钮和其他原生控件均在 shader 外。

球内部对真实背景层进行 RGB 三次采样，包含向内收缩的采样位移、轻微色散、方向高光和边缘 Fresnel。偏移每轴显式限制在 ±38 pt，色散小于 2 pt；声明 `maxSampleOffset` 为每轴 48 pt，取样坐标约束于画布边界。输出保持 premultiplied alpha，避免透明边界产生黑边。它不是单纯模糊或透明填充，也没有读取参考项目的 GPL shader。

## 参考与验证边界

研究材料为 [Appllama liquid-glass-screens](https://github.com/Appllama/liquid-glass-screens) revision `07cb20db94a26790f38166a916bb668e796ad335` 的 README、MOTION_SPEC 和展示图，只研究“穹顶跟随拖动收拢、背景折射、轻色散”的互动概念。双栏构图、应用主题、文案、几何、时序、画布图形与 Metal 实现均为独立创作，没有逐句翻译参考页或复制其品牌资产。

采用本机 macOS `swiftui-patterns` 与 `liquid-glass` 技能，及项目内 SwiftUI Expert、UI/UX Pro Max、Redesign 指导；补读 [Appllama App Design Skill](https://github.com/Appllama/appllama-skills) 的研究优先、原生控件、一次性欢迎页适度 delight、减少动态效果和实际验证要求。其 React Native / 移动端栈由本项目 SwiftUI / macOS 14 的现有架构覆盖。官方 MCP 请求返回 401，因此没有宣称完成 MCP 查询或研究十余张实际屏幕。

官方 `layerEffect` / `ShaderLibrary.default` 文档保存在 `work/onboarding-v1/context7-shader.txt`，本机 SDK 签名已确认。类型检查与 Metal 编译只能证明源代码和 shader 可编译，不能证明已经呈现正确折射、流畅拖动或达到 60 fps。最终主线程需要在真实 `.app` 上验证浅深色、初始收拢、上下和侧向拖动、再次抓取、暂停与 inactive、减少动态效果/透明度、Return / Tab，以及开始设置后的权限流程。60 fps 仍是目标，尚未测量；锁屏状态或截图静态检查不算动效验收。
