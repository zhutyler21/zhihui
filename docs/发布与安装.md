## 拖入安装与首次使用

1. 下载并打开 DMG，把“知会”拖入“应用程序”文件夹；默认位置为 `/Applications/知会.app`。
2. 从安装位置打开应用，按 macOS 提示处理首次打开、麦克风及系统声音访问。
3. 在设置页点击“下载所需模型”，查看进度；需要时可暂停后继续。
4. 两项声音权限和三个模型都准备完成后，点击“进入知会”。

App 内包含 Python 3.12.11、固定 Python 依赖、本地后端和 FFmpeg 8.1.3；无需另装 Python、Homebrew 或 ffmpeg，也无需保留源码仓库。运行文件从当前 App 位置解析，移动应用无需重建。正式包不会改用本机开发环境补足缺失组件。

模型约 2.61 GB，首次准备需要网络；模型完成后推理使用本地文件。模型与缓存位于 `~/Library/Application Support/知会/models/`，会议数据库、录音与附件仍位于 `~/Library/Application Support/知会/`。用户资料不写入应用包；移动或替换 App 不会搬走这些资料。备份时先退出知会，再备份整个资料目录。

公开发行包采用 **ad-hoc 签名，未经过 Apple 公证**。本机开发构建可使用已有的 Apple Development 签名。首次打开或声音权限提示由用户按 macOS 提示处理；本项目不会自动重置授权或关闭系统安全保护。macOS 把系统声音归在“录屏与系统录音”；当前程序保存音频，不保存屏幕图像。

## 源码构建与升级本机旧版

0.8.0 / build 21 已加入 Sparkle 应用内更新；0.5.0 用户需要先手动安装一次 0.8.0。后续通过已签名 GitHub Release 更新，录音与笔记退出保护继续生效。首次发布的密钥备份、更新附件和验收边界见[自动更新与发布](自动更新与发布.md)。0.8.0 正式发行附件与源码以对应 Release 为准。

源码开发环境与独立包的构建过程见 [README 开发与验证](../README.md#开发与验证)。主要入口为：

```sh
bash scripts/build-standalone.sh
python3 scripts/build-dmg.py
python3 scripts/install-app.py
```

项目安装器安装到 `~/Applications/知会.app`，先核验本项目应用身份、运行布局与签名，再在 `work/installed-app-backups/` 备份已有应用。升级原开发版时，安装器按固定模型清单核验并复制可复用的模型到新的用户模型目录；原文件保留，未通过校验的文件由设置页继续准备。会议资料使用原目录，不用旧快照覆盖用户的新操作。操作前先正常退出旧版。

只运行 `scripts/build-app.sh` 得到的仍是依赖项目目录的开发包，不能替代独立版发行流程。开发检查使用仓库 `.venv` 和隔离资料；正式包中运行环境位于 `知会.app/Contents/Resources/Runtime/`，运行时不写入此目录。

### 本机更新的稳定签名

ad-hoc 签名的指定要求绑定当前代码摘要，重新构建后可能无法沿用声音授权。已有有效开发证书的本机可显式选择签名身份：

```sh
ZHIHUI_SIGNING_IDENTITY="证书名称或 SHA-1" bash scripts/build-standalone.sh
```

也可将同一身份保存到不提交的 `work/local-signing-identity`，供开发包与独立包构建共同读取。环境变量优先；未配置身份的其他机器仍使用 ad-hoc。已配置证书不可用时构建失败，不静默换回临时签名。只保存证书标识，不保存或导出私钥。

本机的 0.7.2 开发版采用现有 Apple Development 证书，其指定要求基于应用标识、证书类型和开发团队；后续使用相同身份构建时保持兼容。这不是 Developer ID 分发签名，也没有 Apple 公证。更换应用标识、团队或签名类型不保证授权沿用。依据 Apple [TN3127：代码签名要求](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)，实际授权仍以应用读取的系统状态为准。

## 下载校验

在保存发布附件与校验文件的目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

该命令会核对校验清单中的文件；只下载部分附件时，未下载的条目会报告缺失。校验值证明下载内容与发布附件一致，不证明所有设备的运行状态或模型质量。

## 公开范围与许可

公开内容包括 Swift/Python 源码、构建与验证脚本、固定依赖和模型清单、开发文档及第三方许可。独立 App 分发必要的 Python 运行环境、依赖与 FFmpeg，并保留许可、依赖元数据、FFmpeg 对应源码及构建配置。

本机会议数据库、录音、附件、访问令牌、模型权重、开发用 `.venv/`、`work/` 产物与私人资料不提交源码仓库，也不混入发行包。原有本机开发历史继续保留在本地。
