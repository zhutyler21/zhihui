## 如何使用

**当前 App 是本机开发版，尚不是完整独立安装包。** 它依赖 Python 3.12 环境、项目后端、ffmpeg 和三个模型；构建时的项目绝对路径保存在应用中。把 App ZIP 解压到另一台电脑，并不能自动获得这些运行条件。

其他电脑请优先克隆源码，按 [README 快速开始](../README.md#快速开始) 创建 `.venv`、安装固定依赖、构建并安装。构建脚本会写入本机实际项目路径；首次启动可在设置页下载三个模型，共约 2.61 GB。模型不打包进 Git 或此次 App 附件。

当前应用采用 **ad-hoc 本地签名，未经过 Apple 公证**。源码构建使用相同方式；麦克风与系统声音访问由 macOS 管理，用户按系统提示处理。本项目不会自动重置权限或关闭系统安全保护。

解压 App 可使用 macOS“归档实用工具”。校验下载文件时，在保存 ZIP 与校验文件的文件夹执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

校验值只证明下载文件与发布附件一致，不证明所有设备的运行状态或模型质量。
