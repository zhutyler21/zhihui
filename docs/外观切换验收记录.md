# 外观快捷切换验收

日期：2026-10-14。版本：0.4.1 / build 15。

## 改动

- 主界面左下角移除外观齿轮，只保留单行本机模型状态。
- 右上角原生工具栏加入外观按钮，使用 `moon.fill` / `sun.max.fill`，17 号半粗字重，28 × 28 内容区域，由 macOS 绘制按钮反馈。
- 浅色显示实心月牙，点击切到深色；深色显示实心太阳，点击切到浅色。图标、悬停提示与无障碍名称说明下一步动作，无障碍值说明当前外观。
- 使用同一 `appearanceMode` 偏好；应用菜单的外观设置仍提供跟随系统、浅色、深色。

## 实际验证

`bash scripts/build-app.sh` 成功，输出 0.4.1 / build 15，严格签名验证通过。

独立预览直接使用当前 `RootView`、`SidebarView` 与外观组件，不修改产品权限门禁；使用独立应用标识、偏好域、项目 `work/appearance-toolbar-20261014/data/` 与端口 8795。原生窗口实际观察：

- 左下角没有齿轮，右上角外观按钮排在本地模型按钮之后；最小宽度窗口内可见。
- 点击月牙后，界面进入深色，按钮名称变为“切换到浅色外观”，标识为 `sun.max.fill`；点击太阳后回到浅色，标识为 `moon.fill`。
- 外观设置选择“跟随系统”后，主窗口显示“跟随系统，当前浅色”；下一次点击仍正确切到深色。
- 知识库页面保留相同位置的快捷按钮；正常退出并重开后，浅色偏好保留。
- 使用实际窗口截图检查实心月牙大小、对齐和深浅色阅读对比。

通过 `scripts/install-app.py` 安装一次，旧应用保留在本机备份目录。安装副本与最终构建逐文件 SHA-256 相同；安装前后会议数据库文件哈希相同。

本机验证绑定保存在不提交的 `work/appearance-toolbar-20261014/`：`baseline.json`、`filled-icons-preview-binding.json`、`build15-binding.json` 与数据哈希回执。
