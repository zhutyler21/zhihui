# 知会 0.5.0 · 独立安装验收记录

版本：**0.5.0 / build 16**。发行文件为 `Zhihui-v0.5.0-macOS-arm64.dmg`，适用于 Apple Silicon；应用及捆绑原生依赖的最低构建目标为 **macOS 14.0**。

## 本版交付

应用内包含 CPython 3.12.11、固定 Python 依赖、会议后端与 FFmpeg 8.1.3。运行时按当前 App 位置寻找 `Contents/Resources/Runtime/`，不使用开发仓库的 `.venv`、模型目录或 Homebrew。正式 `Info.plist` 不再包含开发机器的项目根路径，也不包含隔离测试资料或端口配置。

模型不放入 App 或 DMG。首次设置由用户点击下载，使用固定来源、revision、文件大小和 SHA-256；三个模型合计 2.61 GB，保存在 `~/Library/Application Support/知会/models`。会议资料仍在 `~/Library/Application Support/知会/`。本机更新只复制旧模型目录中清单内、大小与哈希均正确的文件，保留来源及目标冲突文件。

MLX 0.32.3 的现成 wheel 要求 macOS 26.2，因此本版使用同版本、未修改的官方源码以 macOS 14 为目标重新构建，保留预编译 Metal 内核、CPU 与 GPU。没有通过修改二进制最低版本字段冒充兼容。源码、构建参数和许可见 [MLX 构建记录](licenses/mlx-source-build/BUILD.md)。

## 验证方法与边界

| 检查 | 本版核对内容 |
| --- | --- |
| Python 回归 | 50 项检查，覆盖实际后端、检索范围、资料恢复、模型下载协议及外部运行目录 |
| 原生回归 | Markdown 保存、应用异步状态、引导与真实进入门禁、模型子进程、退出保护与独立运行路径 |
| 包完整性 | 审计所有 Mach-O 的实际最低系统版本、架构、动态库解析和符号链接；签名后逐文件记录哈希并做深度严格验证 |
| 移动运行 | 把真实签名 App 复制到包含中文与空格的独立临时目录；操作系统禁止它读取原仓库、uv 安装和 Homebrew，禁止写入 App，并禁止外网连接 |
| 真实模型 | 使用核验后的独立模型副本，执行中文音频转换与转写、BGE 索引、Qwen 中文纪要、两场会议范围问答及引用、空会议证据不足处理、导出读回 |
| 原生后端连接 | 从对应冻结源码编译生产 `BackendHost`，在同一隔离条件下启动真实捆绑后端，核对身份、重复启动复用、非拥有者退出保护及拥有的子进程正常停止 |
| 首次下载 | 独立原生欢迎页进入设置；实际公网下载显示字节进度，转写与检索模型完成校验，暂停后显示继续下载；不以该部分传输冒充三个模型全部重下载 |
| DMG | UDZO 安装卷包含 App、指向 `/Applications` 的拖放入口、安装说明和 MIT 许可；只读挂载后核对应用全部字节与深度签名，再卸载本次卷 |
| 安装器与资料保护 | 合成夹具验证原子备份、失败回滚、模型独立复制、冲突保留及数据库字节不变；正式 App 的校验通过。日常资料保留以实际更新后的独立记录为准 |

原始检查记录、失败反例、源码/暂存树/二进制绑定和合成会议保留在本机忽略目录 `work/`。失败与旧版本报告保留原范围，不改成通过。发布附件的实际校验值位于 Release 的 `SHA256SUMS.txt`；对应源码以发行 tag 为准。源码的复杂变更通过暂存树导出后构建并执行移动运行验收，随后进行独立只读复核。

## 尚未证明的范围

- 这是本机 macOS 27 的受控移动运行验收；尚未在另一台真实 Mac 或 macOS 14 实机重复验证。最低构建目标与实际旧系统运行是不同证据。
- 应用采用 ad-hoc 临时签名，未经过 Apple 公证。下载后的首次打开、声音权限校验由用户按系统提示处理。
- 本次没有重置 TCC、移除或重新添加声音权限，也没有用授权替身冒充真实权限。未把本版包装验收描述为一次新的麦克风或系统声音硬件测试。
- 短合成会议的中文纪要与引用问答检查不保证所有长会议的生成质量。模型准备、推理成功与内容质量分开判断。
