# 0.8.0 正式发布与验证范围

版本：0.8.0 / build 21。日期：2026-10-16。发行地址：[GitHub v0.8.0](https://github.com/zhutyler21/zhihui/releases/tag/v0.8.0)。

## 本版内容

- 会议资料与实时会场分工，保留独立多语言翻译大屏；字幕最新置顶，按原文片段对齐。
- 录音与导入使用一组原生操作，来源选择收进菜单；跨页面停止录音栏保持可达，减少空白页重复按钮。
- 转写与笔记默认并排，可切换单栏；点击笔记直接编辑，离开编辑区或完成后预览，保存失败保留草稿。
- 中文纪要可生成简短会议名称，手动命名保持；命名失败仍保留有效纪要。
- Sparkle 2.10.0 检查、下载、签名验证、安装与重启；录音及会议任务期间延后。版本清单与 ZIP 使用原 Ed25519 更新密钥。
- 发布前修复保存语言设置后译文进度停止刷新的问题：成功或失败后继续监控当前会议，旧会议设置请求不打断当前会议。

## 发行附件与安装条件

| 附件 | 用途 |
| --- | --- |
| `Zhihui-v0.8.0-macOS-arm64.dmg` | 首次安装，拖入应用程序 |
| `Zhihui-v0.8.0-macOS-arm64.zip` | 同版完整 App 与应用内更新 |
| `appcast.xml` | 已签名的版本清单，指向本版 ZIP |
| `Zhihui-v0.8.0-source.zip` | 本次发行提交的公开源码与文档 |
| `FFmpeg-v8.1.3-source.tar.xz` | 随 App 分发的 FFmpeg 对应源码 |
| `MLX-v0.32.3-source.tar.gz` | 随 App 分发的 MLX 对应源码 |
| `SHA256SUMS.txt` | 上述发行附件的校验值 |

Apple Silicon、macOS 14+。公开包显式使用 **ad-hoc 签名，未经过 Apple 公证**，更新归档另有 Ed25519 签名；该签名不等于 Apple 公证。首次打开与声音权限由 macOS 实际判断，不自动重置授权或关闭系统保护。项目在本机验证，未宣称跨设备普遍通过。

App 自带独立 Python、固定依赖、后端与 FFmpeg，首次模型准备需网络；模型约 2.61 GB，准备后本地推理。会议、录音、模型在应用外用户资料目录，更新不搬走这些资料。现有 0.5.0 没有更新器，需先手动安装一次 0.8.0；后续在菜单“知会 → 检查更新…”或设置中升级。只推送源码不会产生新的可安装版本。

## 发布检查

原始命令、退出码、源文件与二进制 SHA-256、独立复核及下载回执均留在本机 `work/release-v0.8.0-20261016/`，不作为公开附件。历史记录保留各自版本范围。

- 后端完整回归：80 项，覆盖翻译范围、取消、自动命名、迁移、下载与发布信任边界。
- 原生状态、Markdown 保存、引导、模型准备、引导期间退出、独立运行路径、应用内更新、图标及安装器合成检查。
- 语言设置轮询先保留失败反例，再验证成功、失败及旧会议设置三条真实回环 HTTP 路径。首个夹具路由缺失的检查失败单独保留，不作为产品反例；修正夹具后的反例与修复结果分开记录。
- 准确暂存树导出验证；提交对象、最终构建源码、DMG 与更新归档逐层绑定，打包后检查源码未变化。
- 完整独立包按原生组件审计最低系统、相对依赖、符号链接与嵌套签名；DMG 只读挂载后验证同一个 App。
- 原生界面以独立资料验证录音入口、并排笔记、编辑与预览、深浅色和窄窗口；受控直接入口只证明视图与操作，不证明真实声音授权。
- 移动后的独立运行环境使用合成音频及固定模型检查，不读取日常会议；既有模型质量记录仍限于其已执行样本。
- 通过草稿暂存全部附件，核对后一次公开并设为 Latest。发布后重新下载版本清单和安装包，核对 HTTPS 入口、签名、SHA-256、版本和源码标签。

公开源码不含日常数据库、会议正文、录音、附件、模型权重、访问令牌、更新私钥或本地验收产物。日常资料的精确统计与备份位置只留本机；本次发布不替换日常安装或调整 TCC。

## 证据边界

应用内完整下载、延后、替换和重启已在接入阶段的合成更新应用验证；实际会议保存保护另有原生回归。本次最终公开包的联网检查、附件与运行验证以发布回执为准，不能据此宣称完整真实会议在所有设备上无缝升级。公开 0.8.0 是更新入口的首版，未来版本仍需维护者按[自动更新与发布](自动更新与发布.md)上传签名归档与清单。

翻译与自动命名保留模型误差，需要对照原文校对人名、数字、决定与期限。没有新增长会议耐久性、硬件麦克风/系统声音采集、Apple 公证或跨设备测试结论。
